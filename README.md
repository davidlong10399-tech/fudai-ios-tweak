# 福袋助手 iOS（抖音适配）

Android 版 `福袋助手.apk` 的越狱重写版。仅注入抖音 `com.ss.iphone.ugc.Aweme`，rootless 包。

## 0.4.0 的关键变化：真正会抢了

0.3.0 及之前版本"没效"的原因：只监听了抖音私聊红包类（`AWEIMDouyinRedPacket*`，与直播福袋无关），且触发层只记账、没有任何点击动作。

0.4.0 换成与 Android 版无障碍点击同构的两段式引擎，不依赖抖音内部类名，版本更迭不易失效：

1. **扫描**：每秒在抖音当前窗口树里找文字包含"福袋"的可见标签（关键字可在设置里改）。
2. **点入口**：命中后点击它（UIControl 直接派发，手势视图调用其 action，最多向上找 6 层）。
3. **点参与**：等面板弹出，找包含"参与 / 领取 / 抢福袋 / 立即抢"或一字"开"的按钮并点击；文字以"已"开头（已参与/已领取）则跳过本次。
4. **冷却**：按设置的秒数冷却，之后回到扫描。

安全限制：只在前台运行；设置面板打开/输入时暂停；自己的悬浮窗和面板不会被抓到；全部点击包在异常保护里，命中失败只记日志不崩溃。

## 使用

1. 安装 deb 后重启抖音。
2. 点悬浮按钮打开设置面板，打开"总开关（自动抢福袋）"。
3. 进直播间，悬浮面板状态会显示：运行中 · 扫描 → 已点入口 · 找按钮 → 已点参与 · 冷却中。

## 设置

- 总开关：默认关。
- 入口关键字：默认"福袋"，逗号分隔多个。
- 延迟触发（分）：发现入口到点入口的延迟，默认 0（Android 版的"播完视频再抢"等价物）。
- 冷却时间（秒）：两次抢取间隔，默认 20。
- 每日上限：默认 30，0 不限。
- 调试日志：开 Xcode Console / idevicesyslog 看 `[FuDai]` 前缀日志。
- 生成诊断文件：立即把运行时类/方法扫描结果写入抖音沙盒 `Documents/fudai_dump.txt`（调试模式开启时启动 20 秒后也会自动写一次），用于确认当前抖音版本里福袋相关的真实类名。

## 兼容性说明

- 观察用 hooks（私聊红包类、LuckyCat）保留，但只做日志和冷却联动，不再是功能主体。
- 如果某个直播间按钮是纯自定义手势视图且手势 target 解析失败，日志会显示 `tap: no tappable target`，此时把入口关键字改成面板按钮上的实际文字即可提高命中。
- 快手 iOS 未适配。

## 构建

GitHub Actions（macOS + Theos + Xcode SDK）自动构建 rootless deb，产物在 Actions 制品 `fudai-ios-rootless-deb`。
